# RUNTIME dependencies only. This is what Streamlit Community Cloud installs.
# Keep it minimal: the container has ~1 GB of RAM.
#
# Do NOT add geopandas / GDAL / shapely here. The point-in-polygon borough
# recovery runs OFFLINE on a laptop (spec §6 step 2) and its output is baked
# into the committed Parquet. Shipping the geo stack to Community Cloud is a
# common build failure for zero runtime benefit. Dev-only deps live in
# requirements-dev.txt.
#
# There is also no HTTP client here on purpose. Spec §1.2: the Socrata refresh
# is an offline script, never a runtime path. Nothing in the deployed app makes
# a network call, so nothing in the deployed app can fail on stage.

# Floor of 1.61 inherited from the seed repo, where /qa raised it on 2026-08-09
# (ISSUE-005): the deprecated `use_container_width=True` had a removal date that
# has already passed, and Community Cloud auto-redeploys on every push. Keep the
# floor moving with the call sites or a fix becomes a silent layout regression.
streamlit>=1.61,<2
duckdb>=1.1,<2
pyarrow>=17
pandas>=2.2

# Map. pydeck ships with Streamlit but this app depends on it directly, so it is

# binned, and it is on the tutorial-fingerprint avoid-list.
